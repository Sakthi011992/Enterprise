Phase 4 · UI design for review

Guest QR table ordering

Every screen in the Pegs & Bottles theme, using your real menu. The guest journey is a phone web page opened from the table QR code. The staff screens live in the existing app. Example guests: Deepa and Arun at table R4; waiter Ravi.

Guest journey

Light theme only in v1. Green header carries the venue identity; lacquer red is used only for actions a guest takes. Every state chip uses a word as well as a colour.

Guest screens on desktop and tablet

Same link, same screens; the layout adapts to the width. Phones (under 600 px) use the journey above. Tablets (600–1023 px) show the menu as a two-column grid with the cart in a side drawer. Desktops (1024 px and up) show categories, menu and the cart side by side, so nothing hides behind a button.

Staff side

Reuses the existing app shell, footer navigation and theme. Waiters get a new Guest orders screen; admins get the feature configuration; the floor plan and kitchen display get small additions.

Item states guests see

Derived from the existing order lines and kitchen tickets. No new status column.
